YM비서 개인정보처리방침

시행일: 2026-11-09

1. 누가 쓰는 프로그램인가

YM비서는 개발자 본인(GitHub 계정 simplym73) 한 사람만 쓰는 개인용 프로그램입니다. 다른 사람의 구글 계정 정보를 받지 않습니다.

2. 접근하는 구글 데이터

  • 구글 드라이브의 파일 목록과 정보(이름, 크기, 위치 등), 필요한 경우 파일 내용: 읽기 전용 권한(drive.readonly)
  • 백업 파일을 올리는 용도: 이 프로그램이 직접 만든 파일과 폴더에만 닿는 권한(drive.file)

이 권한은 개발자 본인의 계정에 대해서만 허용했습니다.

3. 사용 목적

본인 자료의 정리, 이름 규칙 맞추기, 검색, 백업입니다. 광고에 쓰지 않습니다.

4. 저장 위치

구글에서 받은 정보는 개발자 본인의 PC와, 본인이 직접 만든 비공개 클라우드 계정(데이터베이스, 코드 저장소)에만 보관합니다. 제3자에게 판매하거나 제공하거나 공개하지 않습니다. 본인이 직접 요청한 기능(요약, 검색)을 위해서만 자료의 일부를 AI 서비스에 보낼 수 있으며, 광고나 판매 목적으로는 쓰지 않습니다.

5. 보관과 삭제

개발자는 언제든 구글 계정의 보안 설정에서 이 프로그램의 접근 권한을 취소할 수 있고, 저장한 파일을 지울 수 있습니다.

6. 구글 정책 준수

YM비서's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. 문의

GitHub 계정 simplym73으로 연락할 수 있습니다.

Summary (English)

YM비서 is a personal tool used only by its developer. It accesses only the developer's own Google Drive data (read-only, plus files the app itself creates for backups) to organize, search and back up the developer's own files. Data is kept on the developer's own PC and private cloud accounts. It is not sold, shared with third parties, or used for advertising. Access can be revoked at any time in the Google Account security settings.
